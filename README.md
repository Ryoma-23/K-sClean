# ケイズクリーン 清掃予約ポータル

歯科医院向けの清掃予約と作業予定を打ち合わせで体験する操作デモです。架空の15医院と6名の作業員を登録しています。先生モードではさくら歯科医院の情報を表示します。

## 起動

この Windows 環境では依存関係と本番ビルドを用意済みです。プロジェクトフォルダーで次を実行すると、pnpm が PATH に入っていなくても起動できます。

```powershell
$node = (Get-Command node.exe -ErrorAction SilentlyContinue).Source
if (-not $node) {
    $node = Join-Path $env:USERPROFILE '.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe'
}
& $node .\node_modules\next\dist\bin\next start --hostname 127.0.0.1
```

ブラウザで [http://127.0.0.1:3000](http://127.0.0.1:3000) を開きます。起動した PowerShell は操作中そのままにし、終了するときは Ctrl+C を押します。

別の環境でセットアップする場合や、開発中の変更をすぐ反映したい場合は、Node.js 20.9 以上と pnpm を用意して次を実行します。

```sh
pnpm install
pnpm dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開きます。

```sh
pnpm typecheck
pnpm lint
pnpm build
pnpm start
```

`pnpm start` は本番ビルドのローカル確認用です。

## 同じネットワーク上の別端末で開く

このPCで本番ビルドを用意し、上の起動手順の最終行を次に置き換えます。

```powershell
& $node .\node_modules\next\dist\bin\next start --hostname 0.0.0.0 --port 3001
```

別端末を同じネットワークにつなぎ、`ipconfig` に表示されるこのPCのIPv4アドレスにポート `3001` を付けて開きます。このPCのアドレスが `192.168.100.90` の場合は [http://192.168.100.90:3001](http://192.168.100.90:3001) です。接続できない場合は、Windows ファイアウォールの受信設定と、両端末間の通信が許可されているかを確認してください。予約とメッセージはブラウザごとに保存されます。

## インターネットから開く

公開中のデモを開きます。起動用のPCや同じネットワークへの接続は不要です。[ケイズクリーンのデモ](https://keizu-clean-demo.vercel.app)

### Vercel に再デプロイする

Vercel CLI でこのフォルダーから公開できます。初回はブラウザで Vercel にログインし、デモを置くアカウントとプロジェクトを選びます。環境変数の設定は不要です。

```powershell
pnpm dlx vercel login
pnpm dlx vercel deploy --prod
```

公開後は、Vercel のプロジェクト画面に表示される本番ドメインを別のネットワークから開いて確認します。デモの操作データは、開いた端末のブラウザに保存されます。

## 打ち合わせ用の操作手順

1. **希望日提出から確定まで**  
   右上の「デモをリセット」で初期状態に戻し、先生モードの「希望日を送る」を開きます。日付を3つ選び、個別に時間帯と備考を入力します。「確認する」から送信するとカレンダーで「日程調整中」と表示されます。作業員モードの「対応待ちの予約」からさくら歯科医院を開き、候補日と担当作業員を選んで確定します。先生モードの予約カレンダーで確定日を確認し、メッセージで自動通知を確認します。確定した予約の他候補はカレンダーの集計から外れます。
2. **木曜日への集中**  
   作業員モードの「予約管理カレンダー」を開きます。初期表示で選択される木曜日に22件の希望候補、1件の確定予約、1件の仮予約があります。日別一覧で状態を切り替えます。
3. **チャット**  
   先生モードのメッセージから送信し、作業員モードのメッセージでさくら歯科医院を開いて返信します。先生モードに戻ると返信が表示されます。
4. **翌年の仮予約**  
   作業員モードで「仮予約を登録」を開き、医院と翌年の予定月または日付を指定します。月のみの仮予約はカレンダー下の「日付未定の仮予約」に表示されます。管理者モードの全体予約カレンダーでも、同じ月を開いて確認できます。

## 画面と保存

- 先生モード：ホーム、希望日入力・確認、予約カレンダー・詳細、メッセージ
- 作業員モード：ダッシュボード、予約管理カレンダー・詳細・確定、仮予約登録、医院別メッセージ
- 管理者モード：管理ダッシュボード、医院検索・詳細、作業員一覧、全体予約カレンダー

Next.js App Router、React、TypeScript、Tailwind CSS、Lucide React を使用します。予約とメッセージはブラウザの localStorage に保存します。初期の日程はデモ開始時の日付を基準に作ります。デモのモード切り替えは表示を切り替える操作です。

## 本番化

本番化には認証とサーバー側の権限チェック、医院ごとのデータ分離、永続ストレージ、予約競合を防ぐトランザクション、監査履歴、通知配信が必要です。デモのメッセージと状態変更は同じブラウザ内で完結します。予約変更とキャンセルは簡易操作で、作業の最適化や外部連携は対象外です。
